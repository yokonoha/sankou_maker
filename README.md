# sankou_maker
参考文献リスト作成支援ソフト - 自動で体裁を整えてクリップボード出力! 執筆のお供になる(かもしれない)便利ツール  
URLを挿入し、パラメータをいじるだけで簡単!  
プレゼン資料の最終ページや論文の後ろに貼り付けるだけでOK!  
卒業論文の執筆に忙しい学生さんにもおススメ!(ソフトウェアの利活用の可否に関しては各教育機関の指示に従ってください。)
